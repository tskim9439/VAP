# raw/ — 원천 자료 (불변)

이 디렉토리는 진실의 원천이다. 에이전트는 여기서 읽기만 하고, 사용자가 명시적으로
요청하지 않는 한 재작성하거나 재편성하지 않는다.

- `inbox/` — 분류 전 스테이징. 어디에 넣을지 모르면 여기 넣는다.
  에이전트가 내용을 읽고 알맞은 폴더로 **이동** 시킨다 (wiki-ingest 스킬).
- `sources/` — 문서, 링크, 트랜스크립트, 익스포트, PDF 등 원천 문서.
- `meetings/` — 합성 전의 거친 회의 메모, 트랜스크립트, 토론 덤프.
- `assets/` — 이미지, 미디어, 스크린샷, 바이너리 첨부.

위 네 폴더에 맞지 않는 자료가 생기면 `raw/<유형>/` 를 lowercase kebab-case 로
새로 만든다.

거친 메모에는 가능하면 작성자 헤더를 붙인다:

```yaml
---
author_id: member-id
created: YYYY-MM-DD
source_type: source-drop | rough-note
---
```

자격증명, 개인정보, API 키는 저장하지 않는다.
