# 전사 라벨 재판정 표본 — 라벨 · Qwen3-ASR-0.6B · Qwen3-ASR-1.7B (2026-10-17, mxc 호스트 GPU 2)

## 배경
- 사용자(2026-10-17): 청취 묶음에서 "정답 전사도 틀린게 있어. Qwen-ASR 등으로 필터링 안했나?", "한국어 데이터도 ASR 대조 했어?", "진행해"
- **현황(학습에 쓰인 정제 파일로 확인):**
  - 한국어 3 코퍼스·KEC·ZTC 는 Qwen3-ASR-0.6B 대조를 했다(2026-09-16 · 10-14). 기준은 오류율 ≥ 0.2 면 전사 감독 제외([[decision-aihub-transcript-policy]])다.
  - 전사 감독 비율: 71631 56 %, 134-1 60 %, 134-2 44 %(발화)
  - otoSpeech 는 대조를 하지 않았다(감독 99 %). NSC 는 라벨 자체가 Qwen·Whisper 일치 결과다.
  - 통과한 한국어 감독 발화 가운데 라벨↔0.6B 오류율 0.1–0.2 가 23–27 %(시간 31–32 %)다.

## 방법 (`experiments/p2_asr_rejudge.py`)
- **표본(seed 0):** 코퍼스마다 전사 감독 발화에서 뽑았다.
  - band: 라벨↔0.6B 오류율 [0.1, 0.2) 150 개
  - control: 오류율 < 0.05 40 개
  - otoSpeech(대조 없음): 무작위 150 개. 0.6B 도 함께 돌렸다.
- 오디오·라벨·오류율 계산은 `p2_asr_check` 와 같다(깨끗한 화자 채널 구간, 한국어 CER 공백 제외·영어 WER).
- **판정(τ = 0.1):** L = 라벨↔1.7B, J = 1.7B↔0.6B
  - 라벨 틀림: J < τ ≤ L
  - 0.6B 틀림: L < τ ≤ J
  - 셋 다 다름: 둘 다 ≥ τ
  - 셋 다 맞음: 둘 다 < τ
- **속도:** 1.7B RTF 0.035(다른 사용자와 GPU 공유, 오디오 35 분을 73 초), 0.6B RTF 0.038

## 읽기 — "라벨 틀림" 은 섞여 있다
- **편집 종류(라벨 → 1.7B):** 한국어 라벨 틀림은 대부분 치환이다(71631 72/87, 134-1 61/78, 134-2 60/71). 짧은 라벨(≤ 8 글자)은 15–25 개다.
- **예로 본 종류:**
  1. 진짜 라벨 오류: "실링" → "힐링", "월만두" → "물만두", "창구 풍물놀이" → "장구"
  2. 표기 관례 차이: "니가"/"네가", "같애"/"같아", "진짜로"/"진짜". 라벨은 소리 나는 대로 적고 ASR 은 표준어로 쓴다.
  3. 숫자 표기: "일 학년"/"1학년"
  4. 두 심판이 같이 틀림: "거품 경제기" → 둘 다 "거품 경쟁이", "어학연수" → 둘 다 "의학 연수". 0.6B·1.7B 는 같은 Qwen3-ASR 계열이라 오류가 겹친다.
  5. otoSpeech: 라벨이 말 반복·간투사를 지운 정리체다("I've I've" → 라벨 "i've", "Um", "Like"). 일부는 구간이 어긋나 전혀 다른 말이 적혀 있다(L 0.71).
- **결론:** 한국어 band 의 절반이 "라벨 틀림" 으로 나오지만, 그 안에 표기 관례와 같은 계열 심판의 공통 오류가 섞여 있다. 진짜 라벨 오류는 그보다 적다. 같은 계열 두 심판의 일치만으로 라벨을 고치거나 버리면 안 된다.

## 평가 창에 주는 영향 (2026-10-18, `noise_vs_err.py`, `eval-noise-vs-error.txt`)
- 사용자: "이게 얼마나 stage 3에서의 문제를 해결할 수 있을지 모르겠네"
- **방법:** 한국어 held-out 창(δ10, 600 개)을 정답 발화 중 라벨↔0.6B 오류율 ≥ 0.1 인 음성의 시간 몫으로 묶었다. 묶음별로 r1 ck2000·p9 ck3000 의 agn·귀속 몫을 봤다.

  | 불일치 음성 몫 | 창 | r1 agn · 귀속 몫 | p9 agn · 귀속 몫 |
  |---|---|---|---|
  | 0–20 % | 108 | 12.7 · 11.4 | 13.3 · 6.2 |
  | 20–40 % | 135 | 15.9 · 10.6 | 16.6 · 8.9 |
  | ≥ 40 %(참조 글자의 34 %) | 211 | 21.4 · 10.8 | 22.4 · 8.0 |

  - 0 % 칸은 전사 감독 음성이 거의 없는 창이라 참조가 짧아 빼고 읽는다(agn 16.0).
- **읽기:**
  - 차이가 전부 라벨 오류 탓이어도 전체 agn 을 부풀리는 몫은 최대 약 2.7 pt 다(0.34 × 8). 실제로는 더 작다. 불일치 창은 음성도 어렵다.
  - 화자 귀속 몫은 불일치 비율과 무관하다.
  - 두 모델이 같은 모양이라 비교 결론은 바뀌지 않는다.
- **결론:** 라벨 정리는 평가 정답을 엄격하게 하고 otoSpeech 를 대조하는 정도로 가볍게 간다.
