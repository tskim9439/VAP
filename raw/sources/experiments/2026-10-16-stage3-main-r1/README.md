- 교대 10 /분 이상 창이 참조 단위의 57 % 다. 평가 셋 대부분이 어려운 구간이다.

## 화자 귀속 오류 유형 분해 (2026-10-17, `attr-errors-*.txt`·`attr-errors-*-summary.json`)
- **도구:** `experiments/cst_attr_errors.py` + `vapasr/data/cst_eval.attr_errors`. 평가 원출력을 디코드 없이 다시 읽는다.
  - 참조는 평가와 같은 코드(`cst_stage3_eval.window_ref`)로 만든다.
  - ck2000·final 모두 2,800 창·δ 의 n_ref·cp·agn 이 원출력과 같았다.
- **방법:**
  - 화자 무시 정렬(agn 과 같은 정렬)에서 짝지은 단위의 슬롯(cp 순열 적용)이 참조와 다르면 '오배정' 이다.
  - 참조 run(시각순으로 한 화자가 이어 말한 구간) 안에서 오배정 덩어리의 위치로 나눈다:
    - 통째(짧은 run ≤ 3 단어 / 긴 run)
    - 늦은 교대(run 첫머리)
    - 이른 교대(run 끝)
    - 헛교대(run 가운데)
  - 통째 오배정은 다시 둘로 나눈다. 홀로는 앞뒤 run 은 맞은 경우다. 이어짐은 연속 run 이 통째로 틀린 경우다.
  - 겹침 = 그 단위 시각에 상대 화자도 말하고 있음
- **ck2000 결과(오배정 = 참조 단위 대비 pt):**

  | | δ10 | δ4 |
  |---|---|---|
  | cp − agn | 11.4 | 12.6 |
  | 오배정 합 | 10.2 | 11.3 |
  | 긴 run 통째 | **5.4 (53 %)** | 6.1 |
  | 짧은 run 통째 | 2.1 (20 %) | 2.2 |
  | 늦은 교대 | 1.2 (12 %) | 1.3 |
  | 이른 교대 | 1.3 (13 %) | 1.5 |
  | 헛교대(턴 중간) | 0.2 (2 %) | 0.2 |
  | 통째 홀로 / 이어짐 | 3.0 / **4.5** | 3.1 / 5.2 |
  | 이어짐 중 창 처음·끝에 닿음 | 67 % | 59 % |
  | 오배정 중 겹침 구간 | 19 % | 19 % |
  | 가설 교대 수 / 참조 교대 수 | 0.91 | 0.94 |

- **읽기:**
  - **경계 시점은 대체로 맞다.** 늦은·이른 교대 덩어리는 중앙값 1 단어(1 단어가 71 %)다. 턴 중간 헛교대는 0.2 pt 다.
  - **오배정의 73 % 는 턴을 통째로 다른 화자에 붙인 것이다.**
    - 긴 턴(4 단어 이상) 통째 오배정은 겹침이 아닌 곳에서 난다(겹침 3 %). 긴 run 의 9.9 % 가 통째로 틀린다.
    - 겹침 탓은 아니다. 오배정 전체에서도 겹침 구간은 19 % 다.
  - **통째 오배정의 60 % 는 연속된 턴의 정체가 함께 뒤바뀐 것이다(4.5 / 7.5 pt).**
    - 두 슬롯 형식에서 교대 하나를 놓치거나 더 내면 그 뒤 턴들의 슬롯이 모두 뒤집힌다. 경계는 맞게 바꾸는데 정체가 반대로 간다.
    - 이 연속 구간의 67 % 는 창 처음이나 끝에 닿는다. cp 는 창 하나에 순열 하나라, 뒤집힌 뒤 되돌아오지 않으면 작은 쪽 조각이 창 끝에 닿는 구간으로 잡힌다. 연속 구간이 있는 창의 run 수 중앙값은 11 이다. 길이 2–4 run 짜리 구간이 무작위 위치에 놓였다면 이 비율은 20–25 % 다.
    - 즉 매핑이 한 번 뒤집히면 대부분 그 창 안에서 되돌아오지 않는다. 모델이 목소리의 절대 정체보다 '목소리가 바뀌었다 → 슬롯을 바꾼다' 는 상대 판단으로 움직이는 것으로 보인다. 학습은 정답 태그를 앞 문맥으로 주므로(teacher forcing) 틀린 매핑에서 되돌아오는 법을 배운 적이 없다.
  - **짧은 턴(≤ 3 단어, 맞장구·짧은 응답):** run 의 51 % 다. 그 가운데 25 % 가 통째로 틀리고, 그 오배정의 56 % 가 겹침 안이다.
  - **교대가 잦을수록 이어짐이 커진다:** 교대 ≥ 20 /분 창은 이어짐 8.4 pt · 홀로 4.5 pt, < 5 /분 창은 0.4 · 0.8 pt 다.
  - **과적합(final, δ10) 때 바뀌는 것:**
    - 가설 교대가 참조보다 많아진다(0.91 → 1.10).
    - 늦은·이른 교대가 2.5 → 3.4 pt, 헛교대가 0.2 → 0.4 pt 로 는다.
    - 이어짐은 4.5 → 5.3 pt 다.
