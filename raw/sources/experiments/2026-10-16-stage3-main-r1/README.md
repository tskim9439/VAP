## 화자 귀속 오류 분석 (ck2000, δ10, 7 코퍼스 1,400 창, `attribution-breakdown-ck2000-d10.txt`, `attr_analysis.py`)

- **귀속 오류는 교대가 잦고 겹치는 창에 몰린다.** 교대 ≥ 20 /분은 < 5 /분의 7 배, 겹침 ≥ 5 % 는 겹침 없는 창의 2.7 배다.
- 한 화자 창(0.5 pt)과 한 화자가 거의 말하는 창(3.2 pt)은 귀속 오류가 작다. 모델은 목소리 하나를 일관되게 한 슬롯에 붙인다. 어려운 것은 교대 지점과 겹침에서 슬롯을 바꾸는 판단이다.
- 교대 10 /분 이상 창이 참조 단위의 57 % 다. 평가 셋 대부분이 어려운 구간이다.
