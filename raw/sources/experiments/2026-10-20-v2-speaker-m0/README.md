# V2 M0 — 인코더 층별 화자 분리도 (2026-10-20)

- 질문(사용자): 화자 귀속 오류가 계속되니, 학습 때 화자 인식 모델로 인코더가 화자를 구분하는 능력을 유지하게 할까? 외부 모듈 없이 하나의 end-to-end 모델이 목표.
- 측정 전 가설: (1) 학습 단계(ASR·번역 목표)를 거치며 인코더의 화자 정보가 지워졌다, 또는 (2) 정보는 있는데 LLM 이 기억·사용하지 못한다.
- 코드: `experiments/spk_probe.py`, 실행 `spk_probe_m0.sh`(mxc 호스트 GPU 하나, 단계당 약 2 분). 집계 `summary.json`·`summary.log`.

## 방법
- 창: Stage 3 회귀 평가와 같은 held-out 창(7 코퍼스 × 200, δ10·맞장구 1.0,3) 중 화자 둘·턴 셋 이상인 906 창, mono 혼합 그대로.
- 턴: 창 안에 통째로 든 1.0 s 이상·다른 화자와 겹침 ≤ 0.2 인 발화(전사 유무 무관). 같은 창 안 턴 쌍 17,176(같은 화자 9,123).
- 특징: NeMo Conformer 층(24 개) 출력과 adapter 출력(= LLM 입력)을 턴 구간 평균. 학습 없는 코사인 비교.
- 지표: EER(턴 쌍), **중심 정확도**(자기를 뺀 화자별 턴 평균 중 가까운 쪽이 자기 화자인 비율 — 슬롯 기억으로 판정할 때의 정확도). raw 와 창 평균을 뺀 cen 두 가지.
- 단계: s0 = Nemotron 원본(Stage 0 은 인코더를 얼렸다), s1 = q06-s1m3-d10, s2 = q06-s4-ast(Stage 2 최종), s3 = p11 ck3000(Stage 3 최종), s4 = st4-m1 ck1500(V1).

## 읽기
- **화자 정보는 인코더 아래층에 충분히 있다**(학습 없이 코사인만으로 같은 창 두 화자를 96 % 가른다). 위층으로 갈수록 지워져 **LLM 이 받는 입력(adapter)에는 69 %(한국어 66 %)만 남는다.** 2 지선다라 50 % 가 찍기다.
- **지워진 것은 Nemotron 원본 인코더(ASR 목표)에서 이미 그렇다.** 우리 학습은 화자 정보를 지우지 않았고 오히려 조금 늘렸다(L12 81.7 → 86.3, adapter cen 51.5 → 55.7 — Stage 3 화자 헤드 이후).
- 따라서 "인코더가 화자 구분 능력을 유지하게 하자"는 처방보다, **아래층에 이미 있는 화자 정보를 LLM 에 직접 넘기는 경로**가 핵심이다. LLM 은 지금 화자 정체 단서가 거의 없는 입력으로 귀속하고 있다 — 교대 시점·내용에 기대다 한 번 놓치면 되돌릴 근거가 없다(연속 뒤바뀜과 맞는다).
