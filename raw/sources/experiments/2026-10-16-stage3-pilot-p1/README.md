## otoSpeech 데이터 결함 두 가지 (Phase 2 부터)
1. **같은 전사 반복:** SRT 는 한 턴을 라벨([Filler]·[Normal Turn] …)마다 하위 구간(간격 1 ms)으로 나누고 하위 구간마다 턴 전체 전사를 되풀이한다.
   - 로더가 하위 구간마다 발화를 만들어 같은 문장이 여러 번 타깃이 됐다.
   - 같은 화자 직전과 같은 전사가 토큰의 6.4 % 였고, 420 대화 중 413 에 있었다.
   - 평가에서는 참조 305 단어 대 가설 75 단어 같은 창이 나왔다.
2. **발화 라벨 누락:** `corpora.SPEECH_LABELS`(6 개)에 없는 라벨의 발화가 모두 빠졌다(`oto_labels.py`·`oto_labels2.py`). 전사가 있는 독립 발화였다(이웃 구간과 전사가 다르다).
   - 빠진 라벨: Strong Floor Hold 12.8 h, Overlap 4.2 h, Reaction Backchannel 0.8 h, 끼어들기 4 종 3.0 h, Bounded Response 0.3 h, Awkward Silence 0.1 h
   - 합계 약 21 h, 라벨 시간의 22 % 다.
   - 빠진 말은 마스크도 없이 '말 없음' 으로 학습됐다.
   - 교대·끼어들기가 빠져 EOT 결과 판정도 틀렸다. 결과 'silence' 가 8,302 개였는데 고친 뒤 1,413 개다.
- **고침(`vapasr/data/dialogue_corpora.load_otospeech_dialogue`):**
  - 같은 화자의 맞닿은(간격 < 0.05 s) 같은 전사 구간을 한 발화로 합친다.
  - 비음성 라벨(Non-Speech Noise·Channel Bleed) 밖 모든 라벨을 발화로 쓴다.
  - `corpora.SPEECH_LABELS` 는 Phase 1 경로가 써서 그대로 둔다.
- **재빌드(`oto_rebuild3.sh`, `oto3-status.txt`):**
