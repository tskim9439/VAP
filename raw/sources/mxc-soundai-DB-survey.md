# mxc `/soundai/DB` 데이터셋 서베이

## (a) 조사 방법 · 날짜 · 제외 규칙

- 조사일: 2026-09-06
- 접속: `ssh mxc '<읽기 전용 명령>'` (BatchMode, 1회 1접속). `ls -la`, `find -maxdepth N`, `file`,
  `cat`(README/메타/JSON), `python3`(로컬 JSON 파싱, 쓰기 없음)만 사용. 삭제·이동·수정·다운로드 없음.
- 대형 트리 전체 `find`(재귀 무제한)는 서버 부하/타임아웃으로 1회 시도 후 중단하고, 이후 폴더별
  `-maxdepth` 제한 탐색으로 전환함(아래 (f) 참고).
- **제외**: 경로에 `phishing` 포함 폴더는 전혀 열지 않음(`/soundai/DB/phishing` 존재만 확인, 목록 미포함).
- 이미 아는 항목(프롬프트에 명시)은 재조사하지 않고 표에는 참조용으로만 포함.
