SEM_END 타임라인

E2 스트리밍 ASR 에 <SEM_END>·<TURN_END> 를 학습한 r1·r2 가 평가 스트림의 어디에서 의미를 확정했는지, 작은 LLM 교사가 매긴 후보 등급(A 확정 · B 애매 · N 금지)과 나란히 본다. 80 ms 청크마다 모델이 <NEXT_AUDIO> 와 경쟁해 커밋을 낸다.

설정별 지표

이 실행에서 읽히는 것

  • ASR 은 지켜졌다. 학습 전 E2+토큰 대비 영어 WER 5.27 → 4.68 %, 한국어 CER 12.72 → 12.80 % (δ4).
  • 한계는 라벨이다. 두 작은 교사의 판정 일치도 κ 0.12–0.21. 영어 문장 끝(LibriSpeech-PC) 353 개 중 A 는 63 개(18 %)뿐이고 201 개는 B 로 가려졌다. 모델 커밋이 문장 끝에 놓인 비율(P_pc 0.62–0.67)은 A 라벨 자체(0.68)와 같다.
  • 한국어 A 의 90 % 는 발화 끝이다. 발화 끝 A 재현 0.80, 중간 A 는 9 개 중 2 개.
  • TURN 은 길이를 외웠다. 영어 학습 스트림 대부분(p10–p90)이 24–34 s 라 22–26 s 부근에서 말하는 도중에도 TURN 을 낸다.
  • N(금지) 라벨의 절반은 좋은 경계였다(블라인드 점검). N 상향 가중을 끈 r2 가 영어에서 조금 낫다.
