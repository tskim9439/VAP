# Phase 2 학습 DB: 무엇부터 사용할 것인가

**먼저 KO 성인 자유대화와 EN otoSpeech를 준비한다.** 그다음 Switchboard 복원과 영어 회의 코퍼스를 추가한다. 결손이 많은 데이터와 시간축 없는 조각은 별도 보조 학습으로 둔다.

최신 사용자 기준(2026-09-11)은 **화자별 독립 채널 또는 그 채널에서 잘린 조각(A등급)을 우선 사용**하는 것이다. 혼합 음성 조각(B등급)을 포함했던 이전 선정안은 대체한다. 모델 입력은 계속 mono이며, 분리 채널은 정렬·화자 라벨·혼합 생성에 사용한다. 모델 구조·블록 규약은 [[output-phase2-streaming-asr-diarization-plan]]을 따른다.

## 1. 먼저 준비할 데이터

‘사용 결정’과 ‘전처리 완료’는 다르다. 아래 데이터도 중복 제거·split·정렬·품질 검사를 마쳐야 학습에 넣는다.

| 언어 | 데이터 | 규모 | 사용할 형태 | 남은 준비 |
|---|---|---:|---|---|
| KO | 성인 자유대화 71631 실내 원본 | 757대화, **196.6 h** | 화자별 stereo 원본 → mono 혼합 | E2 노출 기록, 정렬·라벨 생성 |
| KO | 성인 자유대화 134-1 실외 조각 | 1,492대화 보유, **344.2 h¹** | 화자별 조각을 원 시각에 배치 | 파일–라벨 일치·채널 기원 검증, test 후보 분리, 복원·정렬 |
| EN | otoSpeech | 420대화, 104.9 h 중 **train 약 90 h** | 화자별 wav → mono 혼합 | actor 기준 split, 라이선스 확인, 정렬 |

**계획 규모는 KO 약 540.8 h + EN 약 90 h = 약 631 h**다. 아직 최종 train 총량은 아니다. KO에서 새 test를 떼면 줄어들며, otoSpeech도 split 후 확정한다. 검증 전인 Switchboard는 이 합계에 넣지 않는다.

¹ 344.2 h는 **실외 라벨 1,493대화의 FileLength 합계**다. 보유 조각은 1,492대화이므로 실제 복원·학습 시간은 ID 대조 후 다시 계산한다. ‘약 360 h’는 이전 추정값이다. 조각의 파일 수가 많다는 사실만으로 라벨 전량과 일치한다고 단정하지 않는다.

## 2. 이후 추가할 데이터

### 2.1 자연 대화 확장

| 우선순위 | 데이터 | 규모 | 추가 조건 |
|---|---|---:|---|
| 우선 | Switchboard | 약 230 h 후보 | 화자별 파일과 파일명 시각 검증 → 대화 복원. 편입하면 같은 발화의 replay 제외 |
| 확보 진행 | AMI · ICSI · NOTSOFAR-1 · DiPCo | 약 100 / 72 / 24 / 5 h | **화자별 근접 채널**·어노테이션 확보 및 정합 확인. 전체 코퍼스 규모이며 train 시간은 별도 |
| 확보 진행 | CHiME-6 | 약 50 h | 착용 마이크의 다른 화자 누설이 커 A등급 충족 여부를 먼저 검사 |
| 후속 | CANDOR · Fisher English | 최대 850 / 약 2,000 h | 미확보. 접근·라이선스 확인 후 검토 |
| 제한적 후속 | SpokenWOZ | 249 h, 8 kHz | 화자별 두 트랙이지만 겹침을 억제한 수집. **비겹침 전사·화자 교대용**, overlap 학습용 아님 |

회의 코퍼스 다섯 종은 확보가 결정됐지만 학습 준비 완료는 아니다. 다운로드·서버 경로·라이선스·진행 상태는 [[task-secure-meeting-corpora]] 한 곳에서 관리한다. SpokenWOZ 근거는 [[question-spokenwoz-channel-structure]]를 본다.

### 2.2 결손·시간축 제한이 있는 보조 데이터

| 데이터 | 현재 알려진 상태 | 사용 범위 |
|---|---|---|
| 성인 134-1 실내, 원본 없는 대화 | 약 1,830 h 규모의 라벨; 실내 전체 조각 수/라벨 발화 수 약 45% | 완전 관측 창부터 전사·activity. 결손 인접 구간은 turn 감독 제외 |
| 청소년 134-2 실내/실외 | 라벨 **2,021.7 / 399.9 h**, 조각 수/라벨 발화 수 **72% / 87%** | 채널 기원·대화별 완전성 확인 후 편입. turn 감독은 완전 관측 창만 |
| 복지 콜센터 186 · 연령대별 대화 132 | 화자별 조각 후보, 원 대화 시간축 없음 | 순서·화자 대응 검증 후 전사·태그 보조 학습. 자연 gap/overlap·turn 정답으로 쓰지 않음 |
| CallHome 사본 | 176통화, 발화 약 19.9 h, 8 kHz, 시각 없음 | 위와 같은 보조 학습만 |
| NIKL | 전체 약 3,800 h 자원, Phase 1 표본 사용 중 | 이번에는 replay 유지. 대화 복원은 후속 옵션 |

**라벨 시간 × 파일 보유 비율은 유효 오디오 시간이 아니다.** 발화 길이·무음·중복·누락을 실제로 집계해야 한다. 청소년 조각은 9,470대화에 있지만 이것도 ‘9,470개 완전 대화’라는 뜻은 아니다.

현재 제외: **002_Meeting 등 혼합 녹음 조각**, 화자 분리가 불명확한 128/129 인터뷰, 화자별 채널이 없는 원거리 어레이 사본. AliMeeting은 near-field가 있어도 중국어이므로 EN/KO 주 학습에서 제외하고 head 보조 실험만 후속 후보로 둔다. AISHELL-4는 혼합 어레이·언어 범위 밖이므로 제외한다.

## 3. Replay와 평가는 따로 관리한다

### Replay: 기존 단일 화자 ASR 유지용

| 언어 | 유지할 데이터 | 풀 규모 |
|---|---|---:|
| KO | KsponSpeech 1,189 + NIKL 표본 1,451 + AI Hub 031/033 방송 578 | **3,218 h** |
| EN | LibriSpeech 스트림 1,033 + VoxPopuli 521 + Granary-YODAS 334 | **1,888 h** |
| EN 조건부 | Switchboard 발화 — 자연 대화로 편입하기 전까지만 유지 | **290 h** |

71631 발화 crop 159 h는 자연 대화와 같은 녹음이므로 replay에서 뺀다. 위 수치는 **샘플링 풀**이며 한 epoch에 전부 추가한다는 뜻이 아니다. 혼합 비율은 정본 학습 recipe를 따른다.

합성 overlap 원료는 LibriSpeech·KsponSpeech·NIKL의 train 발화다. 이것도 새 고유 데이터 시간으로 더하지 않으며, 자연 turn 라벨을 만들지 않는다.

### 평가: 학습에서 제외

| 데이터 | 역할 | 주의 |
|---|---|---|
| 71631 실외 stereo 원본 186대화, **51.7 h** | KO dev | E2 dev 재사용. untouched test 아님 |
| otoSpeech의 분리된 actor/대화 | EN dev/test | train과 화자 중복 없는 split을 먼저 고정 |
| 성인 실외 조각 또는 청소년의 미노출 대화 | KO untouched test 후보, 약 5–10 h 제안 | E2의 모든 학습·평가 노출 감사 후 선정 |
| TurnBench dev, **7.3 h** | EN turn 평가 전용 | 이름은 dev 그대로. 공식 test나 미사용 최종 test로 바꾸어 부르지 않음 |

성인 실내 검증 라벨 342.9 h와 청소년 검증 라벨 301.5 h는 원 보고 기준 오디오 미보유이므로 학습·평가 가용량에 넣지 않는다.

## 4. 반드시 지킬 규칙 네 가지

1. **같은 녹음은 한 형태만 쓴다.** 71631 stereo 원본 = 134-1 조각 = Phase 1 aihub71631 crop이다. 원본이 있으면 원본을 우선하고, 원본 없는 대화만 조각으로 복원한다. 원본은 실내 757 + 실외 186대화이며, ‘563’은 조각과 겹치는 실내 부분집합 수이지 원본 총수가 아니다.
2. **split을 복원·crop보다 먼저 정한다.** corpus를 포함한 원 대화 ID와 화자 ID로 train/dev/test를 나눈다. 화자 ID가 대화 안에서만 유효하면 전역 화자 분리를 보장했다고 쓰지 않는다. 성인 71631과 청소년 71632는 별개 자원이다.
3. **정렬 시각과 대화 시각을 구별한다.** ForcedAligner는 발화 안의 단어 시각을 만든다. 잃어버린 대화 내 시작 시각·실제 gap·겹침은 복원하지 못한다. 시간축 없는 조각 연결에는 turn 손실을 주지 않는다.
4. **결손은 무음 정답이 아니다.** 오디오 없는 발화를 zero padding 위에서 학습시키지 않는다. 결손이 영향을 주는 혼합 구간·과거 문맥·미래 라벨 구간을 함께 제외한다. 조각 사이를 채운 무음도 실제 무음 원음과 구분한다.

A등급은 ‘정렬에 적합한 채널 구조’이지 자동 품질 보증이 아니다. 성인 채널 기원 검증은 **2대화·12발화 표본**이다. 청소년 전체에 그대로 적용하지 않는다. 186의 900개 표본도 녹음 메타데이터 조사이므로 파형 누설 검증과 구분한다.

## 5. 바로 할 일

1. **원 대화 ID 대조표와 평가 split 고정** — 원본·조각·replay 중복 및 E2 노출 제거.
2. **우선 데이터 준비** — 71631 원본 + 134-1 실외 + otoSpeech의 복원·정렬·라벨·QC.
3. **작은 검증 통과** — 무음·단독·겹침·결손 사례, serializer 검사, 32창 overfit.
4. **확장** — Switchboard 및 확보된 회의 코퍼스부터. 부분 조각·준자연 스트림은 별도 비교 run.

학습 시작 시 manifest에서 **고유 대화 시간 / 실제 보유 오디오 시간 / 목표별 유효 감독 시간 / train·dev·test 시간**을 각각 출력한다. 최종 학습량은 이 집계로 확정한다.
