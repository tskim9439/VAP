# AMI 결과 총괄 (2026-10-30)

사용자 요청: "현재까지 측정한 AMI 측정 결과를 베이스라인 수치와 함께 정리해줘" → "표를 Offline/Streamable 을 구분하고 끼리끼리 뭉쳐서 정렬해서 쉽게 볼 수 있도록 정리해줘".
- 평가: AMI 공식 eval 16 회의(dev 18 회의), IHM-mix(공식 Mix-Headset)·SDM(Array1-01), 우리 참조(전사 없는 구간은 참조·가설 모두 뺀다), δ10.
- 표 읽기
  - 스트리밍(1 절)과 오프라인(2 절)으로 나눈다. 같은 평가 단위끼리 묶고, 묶음 안은 IHM-mix cpWER 오름차순이다(낮을수록 좋다). **굵은 행**이 우리 모델이다.
  - 수치 열: **직접** = 우리 틀로 잼(같은 회의·참조·마스크, 표준 정규화 + meeteval). **보고** = 남이 보고한 값(조건·정규화가 서로 다르다).
  - 괄호는 dev 다. dev 는 Nemotron 3 Diarization 이 AMI dev 로 학습한 영향이 섞여 있어 판단은 eval 로 한다.
- 정규화: **표준** = Whisper 정규화 + meeteval cpWER(외부 수치와 같은 도구). **우리** = 우리 채점(채움말 남김). 우리 모델은 표준이 우리보다 0.9–1.8 낮다.
- 지연: 우리 δ10 평균 0.92 s, Multitalker Parakeet 1.12 s, VibeVoice-Streaming 2.0 s(15 프레임 1.53 s).
- 공유용 웹 페이지(2026-10-31, 사용자 "공유용 웹 페이지로 만들어줘", 비공개 — 공유는 페이지의 Share 메뉴): https://claude.ai/artifact/SrZjdmP1UrWB3REHkfjX9T
