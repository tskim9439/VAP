# 받아쓰기 오류(agn) 줄이기 — 진단과 종단간 개선안 (2026-11-04)

- 요청: 사용자 "그럼 agn 을 없애려면 어떻게 개선할 지 고민해봐. 종단간 모델구조를 사용할거야."
- 한 줄: 외부 화자 분리기 없는 E13 + G2b 의 cp(24.48 / 36.10)는 대부분 받아쓰기 오류(Whisper agn 21.92 / 28.57)다. 놓친 단어의 절반은 겹친 구간(그중 대부분이 1–10 s 보통 발화의 겹친 부분), 절반은 혼자 말할 때다.

## 1. 지금 수준과 기준
- E13 + G2b 회의 통째(eval, IHM-mix / SDM): cp 24.48 / 36.10, Whisper agn 21.92 / 28.57.
- 외부: Multitalker Parakeet + N3D(직접, 1.12 s) cp 15.86 / 20.50 — 우리 받아쓰기 오류만으로 그쪽 cp 보다 높다. Nemotron 3.5 Transcribe(오프라인) 10.29 / 17.34.
- 이미 아는 것
  - 활동 품질은 받아쓰기 병목이 아니다: 정답 활동(E5, 창) agn 22.4 / 27.8.
  - 화자 조건만으로는 받아쓰기가 좋아지지 않았다: E2(대상 화자 활동을 pre-encode 에 주입 + 화자별 디코드, 정답 활동, 인코더 학습 1e-5) cp 28.56 ≈ 한 스트림 agn 28.31([[output-diarization-integration-20261025]]).
  - 인코더 미리 봄 3 → 13(재학습 없이 평가만, E11 창): agn −0.5 / −0.7.
  - 지연 δ4 → δ10(E5 창): agn −1.2 / −1.8.
  - E7b 부터 LLM 학습에서 인코더는 고정이다(E9·E11·E13·E14 `--freeze-encoder`, 그 전 단계는 인코더 학습률 1e-5). G2b 는 아래 12 층을 화자 분리로 풀었고 학생은 8 층을 탭한다.

## 2. 오류 분해 (`raw/sources/experiments/2026-11-04-agn/agn_diag.py`·`agn_words.py`)
- 방법: 회의 통째 원출력을 참조와 화자 무시로 짝짓는다(같은 글자 ±0.6 s, Whisper 정규화가 지우는 채움말 뺌). 근사 오류는 표준 agn 보다 1.4 안팎 높다(시각 짝 탓).
- E13 + G2b, eval IHM-mix / SDM
  - 근사 오류 23.3 / 30.2 = 삭제꼴 10.6 / 13.5 + 대치꼴 9.5 / 12.9 + 삽입꼴 3.2 / 3.9(그중 참조 무음 1.0 / 1.3).
  - 겹침(그 시각 말하는 참조 화자 수)

| | 참조 단어 몫 | 놓침(삭제 + 대치) | 놓친 단어 중 몫 |
|---|---|---|---|
| 혼자 | 77 % | 12.5 / 18.7 % | 48 / 55 % |
| 둘 | 19 % | 42.9 / 49.8 % | 41 / 36 % |
| 셋 이상 | 4 % | 59.9 / 63.6 % | 11 / 9 % |

  - 겹침 × 발화(episode) 길이: 겹친 말 놓침의 대부분은 1–10 s 보통 발화의 겹친 부분이다(놓친 단어의 38 / 33 %). 짧은 맞장구(< 1 s)의 겹친 부분은 11 / 9 % 다.
    - 혼자 말하는 3–10 s 발화도 놓침 11 / 16 % 로 놓친 단어의 22 / 25 % 를 차지한다(기본 받아쓰기 품질).
  - 짧은 발화(< 1 s)는 33 / 43 % 가 통째로 빠진다(참조 단어의 2.0 / 2.7 %). 발화 첫 단어는 28 / 36 % 를 놓친다(나머지 18 / 23 %).
  - 자주 빠지는 단어: yeah · a · the · it · I · you · okay(맞장구·기능어). 대치는 흩어져 있고(상위 25 쌍이 대치의 6 %) 정규화 차이(okay→ok, yep→yeah 등)는 작다.
  - 게이트 탓이 아니다: 게이트 없는 E11 도 둘 겹침 놓침이 40.4 / 47.4 % 다(E13 43.3 / 49.1).

## 3. 종단간 개선안 (권하는 순서)
1. **E15a — 인코더 위층 공동 학습 + 겹침 많은 데이터 + δ 범위 확대**(구조 변경 없음, 싸다)
   - E13 + G2b 에서 시작해 인코더 13–24 층을 LLM 손실로 함께 학습한다(학생이 탭하는 8 층 아래는 그대로 — 화자 분리 경로 불변).
   - 학습 섞음에서 실제 회의(AMI·ICSI·NOTSOFAR·CHiME-6 근·원거리)와 회의형 합성의 겹침 몫을 올린다.
   - δ 를 4–14 로 학습해 δ10(0.92 s)과 δ13(≈ 1.2 s, Parakeet 1.12 s 수준)을 한 모델로 잰다.
   - 겨냥: 혼자 구간 기본 품질(놓친 단어의 절반), SDM 원거리, 겹침 일부. δ 효과는 E5 의 δ4 → δ10 추세(−1.2 / −1.8)로 보아 δ13 에서 더 준다고 본다.
2. **E15b — 슬롯 조건 인코더 특징**(겹침 겨냥, 구조 변경)
   - 인코더 12 층 출력에 열린 슬롯마다 그 슬롯 활동(학생 예측)으로 화자 커널을 주입하고(SSA·Multitalker Parakeet 의 커널 주입을 층 중간에), 위층을 슬롯마다 돌린 특징을 그 슬롯 태그 임베딩에 더한다.
   - 한 스트림·한 번 디코드 그대로다. LLM 위치 수는 늘지 않는다. 인코더 위층 계산은 열린 슬롯 수만큼(평균 1.07, 겹침 때 2–3)이다.
   - 근거: 놓친 단어의 절반이 보통 발화끼리 겹친 구간이다. 같은 인코더 계열의 Multitalker Parakeet 은 화자 커널로 겹침을 다룬다.
   - 걸리는 점: E2(pre-encode 주입 + 화자별 디코드)는 받아쓰기를 못 올렸다. 차이는 주입 위치(층 중간·위층 학습), 슬롯 블록 한 스트림, 겹침 많은 데이터다. E15a 다음에 겹침 놓침이 그대로면 간다.
3. **짧은 말·게이트 놓침**: X 칸(E14)을 모델이 귀속하게(X 칸에서 화자 슬롯도 낸다). 참조의 2–3 % 몫이다.
- 선택 진단(시스템 제안 아님): AMI 개별 헤드셋 채널을 따로 디코드해 "겹침이 완전히 갈렸을 때" 놓침 상한을 잰다. E15b 의 기대 이득을 미리 가늠한다.
