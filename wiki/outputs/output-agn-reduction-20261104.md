## 3. 종단간 개선안 (권하는 순서)
1. **E15a — 인코더 위층 공동 학습 + 겹침 많은 데이터 + δ 범위 확대**(구조 변경 없음, 싸다)
   - E13 + G2b 에서 시작해 인코더 13–24 층을 LLM 손실로 함께 학습한다(학생이 탭하는 8 층 아래는 그대로 — 화자 분리 경로 불변).
   - 학습 섞음에서 실제 회의(AMI·ICSI·NOTSOFAR·CHiME-6 근·원거리)와 회의형 합성의 겹침 몫을 올린다.
   - δ 를 4–14 로 학습해 δ10(0.92 s)과 δ13(≈ 1.2 s, Parakeet 1.12 s 수준)을 한 모델로 잰다.
   - 겨냥: 혼자 구간 기본 품질(놓친 단어의 절반), SDM 원거리, 겹침 일부. δ 효과는 E5 의 δ4 → δ10 추세(−1.2 / −1.8)로 보아 δ13 에서 더 준다고 본다.
2. **E15b — 슬롯 조건 인코더 특징**(겹침 겨냥, 구조 변경)
   - 인코더 12 층 출력에 열린 슬롯마다 그 슬롯 활동(학생 예측)으로 화자 커널을 주입하고(SSA·Multitalker Parakeet 의 커널 주입을 층 중간에), 위층을 슬롯마다 돌린 특징을 그 슬롯 태그 임베딩에 더한다.
   - 한 스트림·한 번 디코드 그대로다. LLM 위치 수는 늘지 않는다. 인코더 위층 계산은 열린 슬롯 수만큼(평균 1.07, 겹침 때 2–3)이다.
   - 근거: 놓친 단어의 절반이 보통 발화끼리 겹친 구간이다. 같은 인코더 계열의 Multitalker Parakeet 은 화자 커널로 겹침을 다룬다.
   - 걸리는 점: E2(pre-encode 주입 + 화자별 디코드)는 받아쓰기를 못 올렸다. 차이는 주입 위치(층 중간·위층 학습), 슬롯 블록 한 스트림, 겹침 많은 데이터다. E15a 다음에 겹침 놓침이 그대로면 간다.
3. **짧은 말·게이트 놓침**: X 칸(E14)을 모델이 귀속하게(X 칸에서 화자 슬롯도 낸다). 참조의 2–3 % 몫이다.
- 선택 진단(시스템 제안 아님): AMI 개별 헤드셋 채널을 따로 디코드해 "겹침이 완전히 갈렸을 때" 놓침 상한을 잰다. E15b 의 기대 이득을 미리 가늠한다.

## 8. E15b — N3D 활동으로 조건 지은 슬롯별 인코더 위층 (2026-11-06, 구현)
- 사용자: "꼭 종단간 모델이 아니고 N3D 를 활용해서 Parakeet + N3D 보다 우세할 수 있으면 상관 없을거 같은데" → "2번부터 진행해." 목표는 Parakeet + N3D(15.86 / 20.50)를 넘는 것이고, 고정 N3D 활동은 써도 된다. LLM 디코드는 한 스트림 그대로다.
- 근거(7 절): 같은 N3D 활동에서도 격차의 대부분이 겹친 말 받아쓰기(4–5 pt)다. Parakeet 은 활동을 인코더에 주입해 화자마다 조건 지은 특징을 만든다. E15a 절제처럼 인코더를 그냥 풀면 슬롯마다 갈라지는 수단이 없다.
- 구조(`vapasr/hf/slot_enc.py`)
  - 인코더 층 L(기본 16)부터 끝까지를 (섞인 소리 1 + 슬롯 4) 벌로 갈라 돌린다. 아래층은 한 번만 돈다. NeMo 층이 키워드로 불리는 점을 써서 층 L 에 forward pre-hook 을 걸어 입력을 복제·주입하고, 위층에는 배치에 맞춘 마스크를 넣는다.
  - 주입(SlotInject): 슬롯 s 벌 = x + W2·gelu(W1·[x ⊙ a_s, x ⊙ a_others]). 대상 화자(speaker kernel)와 다른 화자 몫을 함께 준다. W2 는 0 으로 초기화한다.
  - 섞인 소리 벌은 주입이 없어 원래 인코더 출력과 같다(E13 오디오 토큰 그대로).
  - 슬롯 벌 출력 → `adapter_slotenc`(주 adapter 복사, 마지막 층 0 초기화) → 그 슬롯 태그 자리에 더한다. E10 의 `slot_x`·`tag_embeds(X)` 경로를 그대로 쓴다. 붙인 직후 출력은 E13 과 같다.
  - 활동: 학습은 태그 활동 입력과 같은 것(N3D ρ 0.9 + 흔든 정답)을 먼저 정한 뒤 인코딩한다. E15b 는 화자 분리 헤드 경로를 쓰지 않는다. 평가는 config 의 N3D 를 회의 전체로 한 번 돌리고(`encode_long`), 조각마다 그 몫으로 조건 짓는다.
  - 연산: 위 8 층 × 5 벌 — 인코더 연산은 약 2.3 배, LLM 은 그대로다.
- 데이터: 겹침 많은 합성 영어 회의 `sim_en-ovl`(`sim-dialogue-v6-ovl`, 1 만 세션 약 260 h, 3–4 인, 끼어들기 0.6·맞장구 3.5 배)
