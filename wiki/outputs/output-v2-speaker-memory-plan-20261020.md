# V2 — end-to-end 화자 기억 (2026-10-20)

## 배경과 제약
- V1 = 지금까지의 프레임워크(Stage 4 최종 st4-m1 ck1500). 화자 귀속 오류가 남는다: 귀속 몫(cp − agn) 5–10 pt, 오배정의 73 % 가 턴 통째, 그 60 % 가 교대 하나를 놓친 뒤 회복하지 못한 연속 뒤바뀜([[output-stage3-prep-plan-20261014]]).
- 사용자 제약: **외부 모듈 없이 하나의 end-to-end 모델.** 화자 인식 모델(ECAPA 등)은 학습 때 교사로만 쓸 수 있다.
- V1 까지 해 본 것: 화자 헤드(cp −4 pt, 유일한 큰 효과), 정체 회복 학습(효과 없음), 화자 헤드 안내 디코딩(삽입 +4 pt 손해), 합성 대화·격리 발화 되살리기(한국어 귀속 8.0 → 6.9).

## M0 — 인코더 층별 화자 분리도 ([[2026-10-20-v2-speaker-m0]])
- 같은 창 두 화자의 턴을 층별 평균 특징으로 가르는 정확도(학습 없는 코사인, 중심 비교):
  - 첫 Conformer 층 96.4 %, 중간(L12) 86.3 %, 마지막 층 66.0 %, **LLM 입력(adapter) 69.0 %(한국어 65.8 %)** — V1 기준
  - Nemotron 원본도 같은 모양이다(마지막 층 63.7 %). 우리 학습이 지운 것이 아니라 ASR 인코더가 원래 위층에서 화자 정보를 버린다. Stage 3 이후 오히려 조금 늘었다.
  - 뒤바뀐 창과 아닌 창의 차이는 작다(첫 층 95.0 대 96.7).
- **결론:** LLM 이 화자 정체 단서가 거의 없는 입력으로 귀속하고 있다. 처방은 "인코더 유지"가 아니라 **아래층의 화자 정보를 LLM 에 넘기는 경로 + 명시적 슬롯 기억**이다.

## V2 설계(초안)
1. **화자 가지:** 인코더 아래층(L00–L03 후보)에서 작은 가지로 화자 특징을 뽑는다. 학습 손실은 창 안 대조(같은 화자 턴은 가깝게, 상대는 멀게) — 정답 화자 라벨로 충분하고, ECAPA 증류는 선택(학습 때만).
2. **슬롯 기억:** 턴이 끝날 때 그 턴의 화자 특징으로 슬롯 A·B 프로필을 누적 평균한다. 학습은 정답 슬롯(일부는 모델 예측 슬롯, scheduled sampling), 추론은 모델이 낸 슬롯으로 갱신 — 턴 뒤 갱신이라 스트리밍 인과성이 유지된다.
3. **주입:** 청크마다 [A 프로필, B 프로필, 지금 화자 특징]을 오디오 임베딩 옆에 넣는다. 화자 헤드도 이 비교를 쓰게 할 수 있다. 창 사이로 프로필을 넘기면 세션 단위 화자 연결(CH109·MLC)도 같은 장치로 풀린다.
- 대안(더 단순): 아래층 특징을 adapter 입력에 더하기만(기억 없음) — 화자 정보 경로만의 효과를 먼저 가르는 대조군.
