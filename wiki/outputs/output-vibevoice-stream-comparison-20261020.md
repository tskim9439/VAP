# 우리 모델 대 VibeVoice-ASR-Streaming-7B (2026-10-20)

같은 평가 셋·같은 참조·같은 채점(cpWER)으로 잰 우리 스트리밍 모델과 VibeVoice-ASR-Streaming-7B 의 비교다. 원자료·스크립트는 [[2026-10-19-stage4-dialogue-translation]] 의 "VibeVoice-ASR 외부 기준선"·"st4-m2a·m2b 결과" 절에 있다.

## 비교 조건

| | 우리 | VibeVoice-ASR-Streaming-7B |
|---|---|---|
| 크기 | 1.21 B(Nemotron 스트리밍 인코더 0.61 B + Qwen3-ASR-0.6B LLM 0.60 B + adapter) | 8.7 B(Qwen2.5-7B + 음향·의미 토크나이저 두 개) |
| 스트리밍 단위·지연 | 80 ms 청크마다 출력, 고정 지연 δ(δ4 = 0.32 s, δ10 = 0.8 s) | 2.93 s 청크 + lookahead 0.53 s |
| 입력 정보 | prefix 로 두 화자의 언어를 준다 | 없음 |
| 화자 | 2 슬롯 태그(A = 창에서 먼저 말한 사람) | 화자 번호(수 제한 없음) |
| 출력 | 두 화자 전사 + 상대 언어 번역(Stage 4) | 전사 |
| 디코드 | greedy | greedy, bf16 |

- 채점: cpWER = 참조 두 화자와 가설 화자의 최적 짝으로 잰 오류율이다. 한국어는 글자, 영어·독일어는 단어 단위다. agn 은 화자를 무시한 오류율이고, cp − agn 이 화자 귀속 몫이다.
- VibeVoice 는 단어 시각을 내지 않는다. 마스크 구간(전사 없는 발화) 거르기는 청크 구간 안 균등 배분으로 근사했다. 그래서 마스크가 많은 한국어 창에서 VibeVoice 가 불리하다(마스크 없는 창 대조를 함께 둔다).

## 요약
- **학습 영역 대화(한국어·독일어)는 우리가 낫고, 영어는 비슷하다.** 우리는 1.2 B·0.8 s 지연이고 VibeVoice 스트리밍은 8.7 B·약 3 s 청크다.
  - 한국어 cpWER 19–35 대 52–105, 독일어 21–30 대 28–34, 영어 27.0 대 26.3(st4-m2a ck2000 은 25.5 로 앞선다)
- **실제 독↔영 전화(TAXI)는 VibeVoice 스트리밍이 낫다.** 전화 대역 증강(st4-m2a)으로 차이가 21.7 → 8.9 pt 로 줄었다(28.1 대 19.2).
- **화자 귀속 몫은 VibeVoice 가 모든 코퍼스에서 0.8–5.2 pt 작다**(3.2–8.3 대 5.2–11.6). 받아쓰기 자체(agn)가 같거나 나은 코퍼스에서도 귀속에서 잃는다.
  - VibeVoice 는 음향 토크나이저(음색이 남는 스트림)와 의미 토크나이저를 더해 LLM 에 넣는다. 우리 LLM 입력에는 화자 정보가 69 % 만 남는다(V2 M0). 그래서 V2-a 두 스트림 입력을 시험한다 → [[output-v2-speaker-memory-plan-20261020]]
- VibeVoice 오프라인(창 전체를 듣는다)은 영어·KEC·ZTC 에서 우리보다 2.6–5.9 pt 낫다(NSC·한국어는 우리가 낫다). 스트리밍 조건의 비교 대상은 아니다.
