## 기여 (설계안 기준)
1. 과제와 평가 프로토콜: 한 mono 스트림, 두 화자, 두 언어. 정답 분할 대 실제 조건 비교로 대화 병목을 번역 품질과 분리
2. CST-Bench: TAXI 실제 트랙(스크립트·설정·체크섬만 배포, 재빌드 86/86 일치) + 영↔독·한↔영 합성 평가 트랙, L0 natural·mediated·L1 조건
3. 검증된 세션 단위 채점기: 방향별 품질·지연·턴 종료 후 지연·전환 지연·잘못된 방향, ASR·diarization 보조 지표, 지표 교란 검증과 합성↔실제 순위 상관
4. 강한 공개 S2TT 시스템의 통제 실험: 정답 요소 요인 실험으로 손실을 분할·라우팅·겹침으로 분해
5. 공개 통합 스트리밍 모델: ASR + 2인 diarization + 양방향 번역(백본 외는 계획)

## 남은 결정 (설계안 권고)
- L1 겹침: 화자 교대마다 U[0.2, 0.8] s, 짧은 턴 길이의 절반으로 상한(E4 에서 확정), 새 설정 이름으로 고정한 뒤 베이스라인 실행
- 맞장구(L1b): **완전히 제외**(2026-10-05 사용자 결정). 원고·표·그림·데이터에서 뺐다.
- 주 품질 지표: COMET·chrF·BLEU 모두 보고. TAXI 에서 COMET 과 chrF 순위가 맞으면 COMET 을 주 지표로
- 주 지연 지표: EndOffset(턴 종료 후 지연) + StreamLAAL(턴 안 지연), 방향 전환은 switch latency. 계산 포함 지연은 부록
- 모델 직렬화: 한 토큰 흐름(백본의 최소 확장, KV 캐시 하나), δ_t 는 {0, 3, 6} 청크 조건 토큰
- 2 단계 초기화: q17-s1 파일럿. 3 epoch 본학습은 영어 악화 분석을 기록하기 전에는 쓰지 않음
- 합성 세트 크기: TAXI 분산으로 검정력 추정 → 1 차분 구축 → CI 폭 보고 확장
- TTS: 상용(Azure) 판이 본 결과, 공개 TTS 판은 일부로 순위 일치만 확인
- 모델 이름: 결과가 나온 뒤 정함(지금은 `\model`)
