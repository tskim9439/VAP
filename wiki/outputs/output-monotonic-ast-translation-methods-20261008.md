# 어순을 맞춘 번역으로 AST 데이터 만들기 — 선행 연구와 제안 (2026-10-08)

## 질문
- 사용자: 기존 영·한·독 전사를 번역해 AST 데이터를 만들 때, 두 언어의 어순을 비슷하게(원문 순서를 최대한 따르게) 번역해 거리를 줄이고 싶다.
- 같은 샘플이라도 영→독, 영→한 번역을 따로 둔다. 내용은 일치하고 문법은 맞아야 한다.

## 선행 연구 (확인한 것, 관측 2026-10-08)

| 연구 | 방법 | 언어 | 핵심 결과 |
|---|---|---|---|
| Simul-MuST-C (Makinae 외, EMNLP 2024) | GPT-4o 에 동시통역의 salami 기법(문장을 의미 단위 조각으로 나눠 순서대로 옮김)을 3 단계로 지시해 MuST-C 번역을 다시 씀 | 영→일·독·중 | 어순 단조성(awesome-align 정렬, Spearman)이 영→일 0.572→0.815, 영→독 0.923→0.972. 품질·지연 이득은 어순이 먼 영→일에서 크고, 영→독은 품질만 약간 낫고 지연은 같음. 생성 비용 1,134 달러 |
| LLM-SI-Corpus (Sakai 외, 2024) | LLM 에 chunk-wise monotonic translation(CWMT) 지침을 줘 기존 ST 코퍼스를 통역식으로 변환. 원문 내용은 모두 유지 | 먼 언어쌍(영→일) | 지연은 줄고 품질은 오프라인 학습 수준 유지 |
| Chen 외 (EMNLP 2021) | 전체 문장 MT 모델을 wait-k 로 디코딩해 재배열이 적은 의사 참조(pseudo-reference)를 만들어 학습에 추가 | 중→영·일→영 | 최대 +2.7 BLEU |
| Han 외 (WMT 2021) | 단어 정렬로 목표문을 조각 단위로 재배열한 뒤 비자기회귀 MT 로 다듬어 문법을 회복. wait-k 를 그 위에서 학습 | — | BLEU 향상, 출력 단조성 증가 |
| Wang 외 (ACL 2023) | 기존 MT 를 교사로 2 단계 beam search 해 단조이면서 정확한 참조를 만들어 증류 | 독→영 등 | 여러 SiMT 기준선보다 좋음. 단조판 WMT15 독→영 테스트에서 이득이 가장 큼 |
| Doi 외 (IWSLT 2024) | 영→일 통역의 어순 분석 | 영→일 | 단조 번역이 어려운 문법 구조를 정리함. 단조 참조로 평가하면 동시 모델이 더 높게 나옴 |
| Stable prefix (Hoang·Axelrod·Post, arXiv 2609.05799, 2026-09) | 원문 prefix 마다 번역해 전체 번역과의 최장 공통 prefix 를 단조 증가로 확정하고, (원문 prefix → 안정 번역 prefix) 쌍으로 Qwen3-8B 미세조정 | 영→독·일·중 | 지연-품질 Pareto 개선, 전체 문장 COMET 도 기준 모델보다 높음. 우리는 이 확정 시점을 번역 단어 방출 시각으로 쓴다([[decision-ast-monotonic-data]]) |
| Simul-COMET (ACL Findings 2026) | 표준 COMET 이 장거리 재배열 번역을 과대평가한다고 보고, 통역식 참조로 학습한 평가 지표 | — | 단조 번역을 평가할 때 참고 |

- 공통 교훈:
  - **완전한 단조는 목표 언어를 부자연스럽게 만든다.** Simul-MuST-C 도 일부 재배열을 허용한다.
  - 이득은 **어순 거리에 비례한다.** 한국어는 일본어처럼 SOV 라 영↔한에서 이득이 클 것으로 보인다. 영↔독은 이미 단조성이 높아(0.92) 이득이 작다. 다만 독일어 종속절의 동사 후치처럼 긴 대기를 만드는 구조는 줄일 수 있다.
  - 실제 통역 데이터는 요약·생략이 많아 학습에 그대로 쓰기 어렵다. 그래서 **번역문을 다시 쓰는 방식**이 주류다.
- 이 표의 수치는 모두 원 논문에서 확인했다. Simul-MuST-C 는 본문 PDF 를, 나머지는 초록·서지 정보를 봤다.
- 실제 통역 코퍼스(NAIST-SIC 등)와 He 외(EMNLP 2015) 의 구문 기반 재작성은 이번에 다시 확인하지 않았다.

## 우리 데이터에 맞춘 제안

1. **번역 방향과 원천**
   - 방향: 영→독·독→영(주), 한→영·영→한(둘째). 원천 하나마다 목표 언어별 번역을 따로 만든다.
   - 입력은 학습 타깃(정규형)이 아니라 구두점이 있는 원출력(`display_text`)이다. 문장 경계와 절 구조가 보여야 조각을 잘 나눈다.
2. **생성: 후보 여러 개**
   - (a) 일반 번역
   - (b) salami/CWMT 단조 번역. 단계는 조각 나누기 → 조각별 순서대로 번역 → 조각 사이 연결만 다듬기이고, 조각 순서는 바꾸지 않는다.
   - 생성 LLM 은 내부 정책상 쓰는 Qwen3.8-27B·EXAONE-4.0 을 쓴다(한국어 쪽은 EXAONE 비교).
3. **관문 1 — 내용 일치**
   - (b) 를 (a) 와 원문에 대조한다: 참조 없는 품질 추정(COMET-Kiwi 계열)과 LLM 판정으로 누락·추가·의미 변경을 본다.
   - 판정 LLM 은 EXAONE-4.0·Qwen3.8-27B 만 쓴다.
4. **관문 2 — 문법**
   - LLM 판정(문법·자연스러움)을 본다.
   - 목표 언어 LM 의 퍼플렉시티가 (a) 대비 지나치게 높으면 탈락시킨다.
5. **관문 3 — 단조성과 실제 지연 (우리만의 장점)**
   - 원문 단어마다 정렬 시각(끝 시각)이 이미 있다.
   - 원문↔번역 단어 정렬(awesome-align 류)로 번역 단어 j 가 나올 수 있는 가장 이른 시각을 구한다: tⱼ = 지금까지 정렬된 원문 단어 끝 시각의 누적 최댓값.
   - 이 값으로 번역에 필요한 지연(오라클 lag, AL 류)을 바로 계산한다.
   - 관문 1·2 를 통과한 후보 중 **오라클 lag 가 가장 작은 것**을 고른다. Spearman 단조성도 함께 기록한다.
6. **학습 타깃 시각**
   - 고른 번역의 단어 방출 시각은 위 tⱼ 에 지연 δ 를 더해 정한다. 이것이 스트리밍 S2TT 학습에 필요한 번역 토큰 시각이 된다.
   - 단조 번역일수록 tⱼ 가 원문 시각에 가깝다.
7. **평가 참조는 따로 둔다**
   - CST-Bench·표준 평가셋 참조는 일반 번역 그대로 둔다.
   - 단조 번역은 학습용이고, 평가에서는 Simul-COMET 같은 보조 지표로만 본다.

- **v1 문제와 v2 수정:** v1 은 단조 번역 통과가 13–26 건이었다. 원인은 두 가지였다.
  - 문법이 깨졌다.
  - 전체 번역과 앞부분 번역의 프롬프트가 달라 확정 시각이 늦게 잡혔다.

## 다음 단계 제안
- **파일럿:** 방향별 1–2 천 발화로 시작한다.
  - (a)/(b) 후보 생성
  - 관문 통과율, Spearman, 오라클 lag 의 분포 확인
  - 사용자가 방향별 50 건을 청취·검토
- **기대 효과 확인:** 영↔한 단조성이 영→일(0.57→0.82)과 비슷하게 크게 오르는지, 영↔독은 얼마나 오르는지(이미 0.92 근처로 예상) 확인한다.
- **규모 결정:** 파일럿 뒤 방향별 학습 시간(예: 1,000 h)과 생성 비용(GPU 시간)을 정한다.
- **차별점:** 기존 연구는 TED(MuST-C) 단방향이었다. 우리는 대화체, 양방향, 영↔한·독→영이고, 정렬 시각 기반 오라클 lag 로 후보를 고른다. CST 논문의 데이터 기여로 검토할 만하다.
