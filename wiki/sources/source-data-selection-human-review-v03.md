## 4. 학습 규약에 대한 해석

사용자는 여러 표본에서 표준어·어법·가독성 면에서 ASR 출력을 선호한다고 밝혔다.
예: `퇴직허고 → 퇴직하고`, `삼 주 → 3주`, 말더듬·filler 제거.
이 선호는 기록하되 **모든 교사 출력을 실제 음성과 일치하는 정답으로 채택하라는 지시와는 구분**한다.

- 원음 충실도, 표준 철자, 숫자 표기, filler·반복 삭제는 서로 다른 변경이다.
- `SDRW2500000325.1.1.130`에서는 사용자가 끝의 `다`가 들린다고 확인했고
  Qwen은 보존하지만 Whisper 둘은 생략했다. 자연스러운 문장일수록 더 정확하다는 규칙은 성립하지 않는다.
- 현행 lexical 타깃·TN 버전은 변경하지 않았다. display 선호를 적용하려면 범위를 별도로 결정하고
  새 규약·타깃 버전과 재정렬 영향까지 관리해야 한다.
- 검수에는 최종 정정문/선택 교사 필드가 없어 `ASR가 더 정확함`만으로 v2/v3/Qwen 중
  하나를 자동 선택할 수 없다. 이번 결과로 교사 전체 순위도 확정하지 않는다.

## 5. 반영 범위와 다음 순서

**2026-09-20 후속:** [[output-data-selection-diagnostic-v04]]에서 아래 검수 연결을 구현하고,
실패 11개 보류·세 우선 진단을 실행했다. 아래는 이 검수를 처음 수신했을 때의 기록이다.

이번에는 **검수 원형 보존·key 검증·원인별 해석·보고서/상태 갱신**을 수행했다.
원음·전사·TN·학습 입력은 변경하지 않았고, 새 GPU 작업이나 전량 screening을 시작하지 않았다.
검수 결과를 학습 판정기에 적용하는 자동 overlay는 아직 구현하지 않았다.

다음 실행은 다음 순서가 타당하다.

1. 명시적 실패 11개와 pass/메모 쟁점을 keyed 검수 예외표로 연결한다.
   사람 fail이 교사 합의로 덮이지 않게 하고, 실패 표본을 대화에서 삭제해 시간축을 압축하지 않는다.
2. 방송 반복 타깃의 생성 이력, NIKL/VoxPopuli 경계 의심, AMI 낮은 청취 레벨·crop을 우선 진단한다.
   이미 검수한 32개 전체를 다시 요청하지 말고 해결되지 않은 항목만 정정문·원인 확인을 받는다.
3. 명확한 실제 단어 교정과 display 선호를 분리하고, 필요할 때만 규약 변경을 질문한다.
4. DB별 추가 calibration 후 통과한 범위부터 전량 선별한다. NIKL 2025의 8개 pass는
   해당 표본을 지지하지만 연도 전체의 정확한 원대화 원점·단어 타이밍 승인은 아니다.
   방송의 채널 pass 6개도 서로 다른 채널 2,939개 전체에 대한 선택 규칙을 확정하지 않는다.

**VoxPopuli의 VAD 길이 일치와 AMI의 두 채널 동일성이라는 기술 결론은 유지**된다.
이번 검수는 그것들이 전사·청취 품질을 보장하지 않음을 보여준다. 두 결론을 혼동하지 않는다.

구체 실행안: [[output-data-selection-diagnostic-protocol]]. 코드 확인 결과 방송 `raw_text`는
철자전사, 타깃은 발음전사를 사용한다. 필드 차이가 의도된 것인지 원 JSON 대조가 먼저이며,
현재의 반복 수 차이만으로 TN 버그를 확정하지 않는다.
