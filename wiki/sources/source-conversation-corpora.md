# 대화 코퍼스 정리

VAP 학습의 전제는 **화자별 분리 채널** 이다. 채널 구조가 곧 사용 가능 여부를 결정한다.

| 코퍼스 | 규모 | 채널 | 언어 | 라이선스 / 접근 |
|--------|-----:|------|------|------------------|
| AI Hub 감정 태깅 자유대화 (서버 보유: VS_02 51.7 h + TS_01_5 196.6 h) | 성인 **2,765 h(실측)** + 청소년 3,000h | **stereo 실물 확인** (16 kHz, 누설 −64 dB) | KO | 내국인 한정 승인, 재배포 제약. **API 키로 서버 직접 수신 가능** |
| otoSpeech (TurnBench 학습셋) | 104 h | dual-channel | EN | custom **non-commercial**, voice cloning 금지 |
| CANDOR | 1,656 대화 / 850h+ | **화자별 분리 채널** | EN | **CC BY-NC** |
| SpokenWOZ | 249 h | 전화 human-to-human, **채널 구조 미확인** | EN | → [[question-spokenwoz-channel-structure]] |
| KsponSpeech | 1,000 h | 단일 발화 ASR 용 (대화 아님) | KO | ASR adaptation 용도로만 |

## AI Hub 감정 태깅 자유대화 (핵심 학습 자원)

- 청소년판: 3,000시간, 4,433명(10–19세), 16 kHz / 16-bit **stereo**,
  각 화자를 mono 로 따로 녹음해 stereo 로 병합. 앱 기반 무대본 수집.
- 어노테이션: 화자별 전사, **발화 시작/종료 타임스탬프**, 화자 턴,
  7종 감정 태그 + 강도(약/중/강) + 극성, 대화 주제.
- **초안의 "VAP training 에 거의 이상적" 이라는 판단은 맞다.** stereo + 발화
  타임스탬프가 이미 있어 forced alignment 없이도 VAD/VAP target 을 만들 수 있다.

### 실물 검증 (VS_02.실외 100개 무작위, 2026-09-03)

원본: `raw/sources/experiments/2026-09-03-aihub-71631-vs02-verify.json`

| 항목 | 값 | 판정 |
|------|-----|------|
| 실제 포맷 | **16 kHz / 2 ch / PCM_16** (라벨 JSON 의 48000 은 원본 녹음 표기) | 스펙 페이지가 맞음 |
| 채널 누설 (A 발화 중 B 채널 에너지) | 중앙값 **−64 dB**, p90 −35 dB | 진짜 분리 |
| 채널 상관 | 6e-5 | 진짜 분리 |
| overlap 비율 (에너지 VAD) | 중앙값 7.4 %, 평균 8.9 % | 실제 대화 역학 있음 |
| 라벨 StartTime vs VAD 온셋 | **중앙값 30 ms**, 평균 187, p90 370 ms | 시작은 정확, 꼬리 김 |

**주의 — 타임스탬프는 전사용 발화 구간이지 정밀 VAD 경계가 아니다.** (라벨 통계의 '겹침 50 %' 는
실물 검증 결과 발화 **끝**이 넉넉히 잡힌 탓이다 — 시작 시각은 중앙값 30 ms 로 정확하다.) 화자 교대의 **50 %** 가
"겹침" 으로 잡히고 겹침 중앙값이 1.0 s, gap 중앙값도 0.98 s 다. 실제 대화의 gap/overlap 은 수백 ms 단위이므로
이 수치는 발화 경계가 넉넉하게 잡혔음을 뜻한다. → **VAP target 은 라벨 시간이 아니라 채널별 에너지 VAD 로
만들고, 라벨은 화자 식별·텍스트에만 쓴다.** 라벨 시간 vs VAD 온셋 오차는 실물 검증에서 정량화한다.

### 그러나 두 가지 제약

1. **접근**: 내국인만 신청 가능, 승인 필요. **API 키 발급·aihubshell 불가, PC 브라우저 다운로드만 가능**
   (2026-09-03 사용자 확인). 서버로는 로컬 PC 경유 전송이 유일한 경로 → 전체 6,000 h 반입은 비현실적이며
   **필요한 파트만 선별 반입**해야 한다. 이는 [[source-conversation-corpora]] 의 "1,000 h 로 시작" 을 넘어
   **50–100 h 서브셋으로 시작**해야 하는 실무적 이유가 된다.
   외부 공동연구자·리뷰어가 재현할 수 없다.
2. **재배포**: 승인된 사용자로 한정. → **AI Hub 오디오 기반 "Korean TurnBench" 를
   그대로 공개 배포할 수 없다.** → [[decision-korean-benchmark-release-scope]]

## CANDOR

video chat 기반 무대본 dyadic 대화. **화자별 분리 채널이라 diarization 불필요.**
CC BY-NC — 비상업 연구는 가능하나 상업적 파생물은 불가. video chat 특성상
네트워크 지연·에코가 timing 라벨에 영향을 줄 수 있어 전처리 검증이 필요하다.

## 초안 대비 수정 사항

초안은 "처음부터 6,000시간을 쓰지 말고 KO 1,000h 로 시작" 을 권했는데 이는 타당하다.
다만 **1,000시간도 Stage 1 probing 에는 과하다.** frozen encoder probing 은
50–100시간이면 encoder 간 순위가 안정된다. 데이터를 늘리기 전에
[[task-stage1-encoder-probing]] 의 결론을 먼저 낸다.
